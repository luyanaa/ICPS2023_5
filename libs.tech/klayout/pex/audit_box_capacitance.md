# BOX 电容物理确权：0.086 fF/µm² 的物理对端为底层公共衬底 (SUB)

状态：**已确权**（2026-10-17，工作线 B-1）。本文件把 PEX 装配链路中
"扩散电容 → 全局 SUB" 从 *显式建模假设* 升级为 *经解析交叉验证的物理确权*，
并保留其边界条件。AGENTS.md §4.2 第一项。

## 1. 被确权的量

PDK `PDK_minimalFabSOICMOS.pdf` p.9（MOSFET Capacitance）给出实测 N/P 扩散
电容密度：

    CNdiff / CPdiff = 0.086 fF/µm²  （三位有效数字）

p.9 与 p.4 均未声明该电容的回路端子。PEX（`icps2023_5_pex.py` 的
`CAP_TO_SUB`）把该密度挂在合格无源扩散区与全局 `SUB` 之间。

## 2. 解析对端：400 nm BOX 理想平行板

同谱系工艺先验（2020 产总研/Minimal Fab 文献，AGENTS.md §2.3 Level 2）：
埋氧 `T_BOX = 400 nm`，SiO2 `εr = 3.9`。理想平行板密度：

    C_BOX/A = ε0 · εr / T_BOX
            = (8.854×10⁻¹² F/m · 3.9) / (400×10⁻⁹ m)
            = 8.6327×10⁻⁵ F/m²
            = 0.086327 fF/µm²          （≈ 8.63 fF / 100 µm²）

与实测 0.086 fF/µm² 的偏差：

    (0.086 − 0.086327) / 0.086327 = −0.38 %

完全在实测值三位有效数字的舍入范围内（±0.6% 量级）。

## 3. 为什么这构成"端子确权"而不只是数值巧合

1. **SOI 结构上扩散区到衬底没有其它并联回路**：扩散区与底层衬底之间隔着
   400 nm 埋氧（绝缘体），不存在结耗尽项；扩散区对衬底的静态电容由
   BOX 平行板项主导。若回路面是别的导体（如 ML1），密度将取决于布线
   几何而非一个工艺常数，不可能与仅由 T_BOX、εr 决定的数值吻合。
2. **密度量级唯一匹配 BOX**：15 nm 栅氧的平行板密度是
   0.0863 × (400/15) ≈ 2.30 fF/µm²——正好是 p.9 CAP 窗口器件的
   2.3 fF/µm²。同一张表上两个密度（0.086 与 2.3）之比恰为膜厚之比
   （400/15 = 26.7），说明两个测量各自对应明确的介质厚度：
   0.086 ↔ BOX 400 nm（扩散↔衬底），2.3 ↔ 栅氧/CAP 介质（栅↔扩散或
   TiN↔Al）。这排除了"0.086 是某种其它介质项"的可能。
3. **FEM 边缘修正方向一致**：`fieldsolve_box.py` 的 2-D FEM 研究
   （pex/README.md）显示有限宽度条带相对无限板 0.0863283 fF/µm² 的偏差
   随宽度收窄而增大（100 µm 条带 +0.4%，10 µm +3.7%，1 µm +37%）。
   实测值与无限板极限差 <0.4%，说明测量结构是面积主导的大面积版图，
   与 p.9 大尺寸测量结构一致；这也解释了为何不需要边缘项即可闭合。
4. **同谱系文献独立印证**：2020 小粥文献的 FD 设计与 TEG 结构均以底层
   公共衬底为统一背面端子（AGENTS.md §1.3 四端 D/G/S/E 契约的 E 端）。

## 4. 确权结论与边界

**结论**：p.9 的 0.086 fF/µm² 的物理对端是"扩散区 → 底层公共衬底"，
即 PDK 四端 MOS 契约中的统一 `SUB` 端子。PEX 的 `CAP_TO_SUB` 映射
自本确权起为**物理确权映射**，不再是自由建模选择。

**边界（保留，不因确权而消失）**：

- 该确权只覆盖**面积项**。p.9 未提供周长/边缘项（overlap 5/6.8 fF/µm
  是栅的一维项，不适用于扩散边缘），PEX 因此仍不发明周长规则。
- 确权不改变器件所有权：MOS-access、RES、显式 CAP、DIO 区域仍从该
  密度中排除；2.3 fF/µm² 的 CAP 窗口是另一种器件（介质厚度不同），
  不得与 0.086 合并。
- `AIST-SOI-CMOS.xs`（2021 断面）与 2023 PDK 的介质栈差异（README
  "stack discrepancy"）仍按原文保留：本确权只使用 400 nm BOX 这一个
  尺寸，该尺寸在两份资料中一致，故确权不依赖未决的整栈问题。
- 该密度是 25 °C 单点实测；温度系数未表征，不得外推全温区
  （AGENTS.md §5 Level 1 边界）。

## 5. 对下游的约束

- `assemble_postlayout.py` 与后续 Liberty/PEX 装配必须保持扩散电容
  对 `SUB`（即顶层 `E_SUB`）的连接拓扑，不得把 SUB 回路改挂到其它
  端子或浮空。
- 背栅 C–V 一旦有实测（AGENTS.md §6 TEG 强制项 1），须回代检验本
  确权（背栅偏置下 BOX 电容应基本不变；若实测扩散电容随 V_SUB 强烈
  变化，则说明存在本确权未覆盖的中性体/背栅耦合项，须重新开案）。
