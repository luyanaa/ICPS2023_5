# BOX 电容证据等级：0.086 fF/µm² 的候选物理对端分析

状态：**BOX_RETURN_ANALYTICALLY_SUPPORTED / MEASUREMENT_UNCONFIRMED**（2026-10-19 降级修订）。

本文件原先将该映射记为"物理确权"，该表述超出证据强度，现予纠正：解析数值吻合
支持"埋氧（BOX）是 0.086 fF/µm² 面积项的最强候选物理解释"，但不能独立证明
测量仪器回路的实际对端电极，也不能证明 PDK 表格密度与同一几何公式的推导关系。
PEX 的 `CAP_TO_SUB` 因此是**显式建模契约（modeling contract）**，不是经实测
确权的端子识别。

## 1. 被审计的量

PDK `PDK_minimalFabSOICMOS.pdf` p.9（MOSFET Capacitance）给出实测 N/P 扩散
电容密度：

    CNdiff / CPdiff = 0.086 fF/µm²  （表格按三位小数显示，本身只有两位有效数字）

p.9 与 p.4 均未声明该电容的回路端子。PEX（`icps2023_5_pex.py` 的
`CAP_TO_SUB`）把该密度挂在合格无源扩散区与全局 `SUB` 之间。

## 2. 解析候选：400 nm BOX 理想平行板

同谱系工艺先验（2020 产总研/Minimal Fab 文献，AGENTS.md §2.3 Level 2）：
埋氧 `T_BOX = 400 nm`，SiO2 `εr = 3.9`。理想平行板密度：

    C_BOX/A = ε0 · εr / T_BOX
            = (8.854×10⁻¹² F/m · 3.9) / (400×10⁻⁹ m)
            = 8.6327×10⁻⁵ F/m²
            = 0.086327 fF/µm²          （≈ 8.63 fF / 100 µm²）

与实测 0.086 fF/µm² 的偏差：

    (0.086 − 0.086327) / 0.086327 ≈ −0.38 %

该差值在表格显示位数的舍入范围内（±0.6% 量级），但**不构成测量误差棒**：
显示值与无限板极限的差值不能当作实测精度证据。

## 3. 支持性论证（为什么 BOX 是候选，而不是数值巧合）

1. **SOI 结构上扩散区到衬底没有其它并联回路**：扩散区与底层衬底之间隔着
   400 nm 埋氧（绝缘体），不存在结耗尽项；扩散区对衬底的静态电容由
   BOX 平行板项主导。若回路面是别的导体（如 ML1），密度将取决于布线
   几何而非一个工艺常数，不易与仅由 T_BOX、εr 决定的数值吻合。
2. **密度量级唯一匹配 BOX**：15 nm 栅氧的平行板密度是
   0.0863 × (400/15) ≈ 2.30 fF/µm²——正是 p.9 CAP 窗口器件的
   2.3 fF/µm²。同一张表上两个密度（0.086 与 2.3）之比恰为膜厚之比
   （400/15 = 26.7），与"两个测量各自对应明确介质厚度"的解释一致。
3. **FEM 边缘修正确认了面积主导**：`fieldsolve_box.py` 的 2-D FEM 研究
   （pex/README.md）显示有限宽度条带相对无限板 0.0863283 fF/µm² 的偏差
   随宽度收窄而增大（100 µm 条带 +0.4%，10 µm +3.7%，1 µm +37%）。
   表格值与无限板极限差 <0.4%，与"大面积版图、面积主导"的测量结构一致。
4. **同谱系文献独立印证**：2020 小粥文献的 FD 设计与 TEG 结构均以底层
   公共衬底为统一背面端子（AGENTS.md §1.3 四端 D/G/S/E 契约的 E 端）。

## 4. 证据缺口（为什么不能升级为"确权"）

- 上述均为**已公开数据的自洽性检验**，不含任何独立的回路端子测量（如
  背栅 C–V 的极性/偏置响应、开尔文结构或探针对端确认）。
- 无法排除：(a) 表格密度由与 BOX 平行板不同的几何假设估算；
  (b) 测量回路经由其它端子或探针配置形成等效面积项；
  (c) 存在中性体区/背栅耦合项与 BOX 项在同一表格数值内混合。
- 因此本文件的结论仅为：**BOX→SUB 是当前可用的、解析上最自洽的映射契约**，
  适用于 PEX/装配链路的显式记账；它不是实测端子识别。

## 5. 当前结论与边界

**结论（修正后）**：p.9 的 0.086 fF/µm² 的最强候选物理对端是
"扩散区 → 底层公共衬底"（PDK 四端 MOS 契约中的统一 `SUB` 端子）。
PEX 的 `CAP_TO_SUB` 映射按**显式建模契约**执行，并保留下述边界。

**边界（保留）**：

- 该映射只覆盖**面积项**。p.9 未提供周长/边缘项（overlap 5/6.8 fF/µm
  是栅的一维项，不适用于扩散边缘），PEX 因此仍不发明周长规则。
- 不改写器件所有权：MOS-access、RES、显式 CAP、DIO 区域仍从该
  密度中排除；2.3 fF/µm² 的 CAP 窗口是另一种器件（介质厚度不同），
  不得与 0.086 合并。
- `AIST-SOI-CMOS.xs`（2021 断面）与 2023 PDK 的介质栈差异（250 nm 第一
  TEOS vs 器件断面 300 nm TEOS）仍按原文保留：本分析只使用 400 nm BOX
  这一个尺寸，该尺寸在两份资料中一致，但整栈尚未完成版本级对应。
- 该密度是 25 °C 单点表格值；温度系数未表征，不得外推全温区
  （AGENTS.md §5 Level 1 边界）。
- 一旦有实测（AGENTS.md §6 TEG 强制项 1 的背栅偏置扫描、15 nm 栅氧
  MOSCAP），须回代检验：若实测扩散电容随 V_SUB 强烈变化，或回路对端
  并非衬底，则本映射契约须重开案。

## 6. 对下游的约束

- `assemble_postlayout.py` 与后续 Liberty/PEX 装配必须保持扩散电容
  对 `SUB`（即顶层 `E_SUB`）的连接拓扑，不得把 SUB 回路改挂到其它
  端子或浮空；这属于接口契约，不因证据降级而放宽。
- 寄生归属分工的总表见 `pex/README.md` 的 capacitance ownership matrix：
  每个物理项只有一个实现所有者（BSIMSOI / LVS 器件 / PEX），未来引入
  更完整场求解器时不得重复计入模型重叠电容或已归属的器件窗口。
- 实现层"单一所有者"不等于物理层已完成去嵌入：该区分必须随所有引用
  本文件的结果一并声明。
